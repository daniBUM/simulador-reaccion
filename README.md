# Simulador de Reacción

Simulador para practicar entradas en la golden zone (Fib 0,78-1) de XAUUSD con ticks reales, reproducidos como en directo. Se instala desde el navegador del movil: menu > Instalar app / Anadir a pantalla de inicio.

Las decisiones se guardan en el propio telefono y se exportan con el boton "Exportar mis decisiones".
